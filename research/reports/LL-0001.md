# LL-0001 — Runner invocation failure

## Outcome

All 24 planned runs failed before subject-agent execution. `codex exec` rejected
the runner's `-a never` argument because approval-policy selection is a top-level
interactive CLI option but not an option of this installed `codex exec`
subcommand.

No model calls completed, no behavioral outputs exist, and no condition can be
scored. The failed run remains preserved under
`research/evidence/pilot/LL-0001/`.

## Prediction difference

The harness model incorrectly generalized a top-level CLI option to the
non-interactive subcommand despite having inspected both help surfaces. The
shared invocation defect explains the immediate, identical failures across all
conditions and worlds.

Future action changes as follows: validate the exact constructed subcommand,
not a neighboring help surface, and preserve CLI invocation failures as their
own experiment rather than overwriting the allocation.

## Disposition

`rejected` as a harness execution. `LL-0002` changes only the unsupported CLI
argument and receives a new evidence directory and experiment identity.
