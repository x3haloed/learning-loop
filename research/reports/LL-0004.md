## Interpretation

This run still does not show a clean intervention separation:

- Current-loop controls dominate Bayesian posterior accuracy regardless of prompt style.
- Replacing explicit contract text with ordinary prompt text materially improved fixed-checkpoint calibration for current-loop (`0.0267` vs `0.0589`).
- `no-loop` outcomes were mixed: plain and contract both matched or exceeded current-loop on some dimensions, with `no-loop-plain` showing weaker posterior-coherence calibration (`0.0756` Bayes L1) than `no-loop-contract` (`0.0042`).
- Probe selection and both action endpoints still heavily favored by all conditions, with no meaningful decision-action ceiling break.

In short: the 2×2 contrast is informative but still inconclusive. The explicit contract machinery did not produce a dominant advantage, and prompt style interacts with probe and posterior behavior in ways that depend on condition.

## Disposition

`LL-0004` is a continuation result from a conditional phase and does not justify intervention promotion.
The strongest open question remains whether non-contract prompt variants create a repeatable transfer edge when decision and action endpoints are no longer ceilinged.
